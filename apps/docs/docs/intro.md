# Introduction

Insane-forms binds UI controls to Zod schemas and renders their composition.
Specialize reusable fields with Zod, then place them in groups and lists: that
placement supplies their form-state paths. The library supplements a state engine
such as React Hook Form rather than replacing it.

Start with [core concepts](./guides/core-concepts.md) and
[binding a design system](./guides/binding-a-design-system.md). The
[component explorer](/insane-forms/explore) contains live examples and source.
The [design reference](./guides/design-reference.md) distinguishes current behavior,
intended contracts, and known gaps. Runtime examples do not establish that every
Zod derivation or initialization case is supported.
