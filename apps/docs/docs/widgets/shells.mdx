# Shells

_Placeholder page — real prose (the `fieldShell`/`fieldSetShell` contract,
writing a custom shell) goes here._

A shell is the layout/label/error chrome wrapped around a widget — not the
widget itself. The same shell works regardless of which widget it wraps, so
a design system implements it once and every field gets consistent spacing,
labeling, and error placement for free.
