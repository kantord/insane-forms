# Toggle

_Placeholder page — real prose (single toggle vs. a toggle group over an
enum, single vs. multi-select) goes here._

A single `Toggle` is just another `z.boolean()` widget, styled as a pressable
button instead of a switch. `ToggleGroup` goes further: it binds a single
`z.enum([...])` for one-of-many selection, or a `z.array()` of an enum for
many-of-many — one widget, two schema shapes.
