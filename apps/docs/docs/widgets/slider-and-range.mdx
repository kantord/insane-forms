# Slider & range

_Placeholder page — real prose (numeric schema bounds driving the control's
min/max/step) goes here._

Both bind a `z.number()` — `Slider` picks one value, `Range` picks two (a
`min`/`max` pair), so reach for `Range` whenever the schema itself is a pair
of bounded numbers, not a single one.
